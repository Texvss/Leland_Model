================================================================================
WHY H1 FAILED: THEORETICAL ANALYSIS
================================================================================

1. MATHEMATICAL OPTIMALITY OF CLASSICAL LELAND
-----------------------------------------------

Leland (1985) derived A parameter from first principles:

  A = (k/σ) × √(8/(π×Δt))

This formula is mathematically OPTIMAL under:
  ✓ Geometric Brownian Motion (GBM) assumption
  ✓ Proportional transaction costs
  ✓ Continuous-time limit approximation
  ✓ Delta hedging strategy

The derivation minimizes total cost = hedging error variance + transaction costs

Key insight: This is NOT an approximation - it's the EXACT solution
            under stated assumptions!

2. OVERFITTING PROBLEM
----------------------

Grid Search Optimization Process:
  - Sample: 2,000-10,000 Monte Carlo paths
  - Test: 11 values of A in range [A_classical - 0.3, A_classical + 0.3]
  - Select: A with minimum std on THIS SPECIFIC SAMPLE

Problem: Monte Carlo sample is finite → has sampling noise

Example (TSLA, k=0.005):
  Classical A = 0.2153
  Optimized A = 0.1546  (28% lower!)

  On calibration sample (2,000 paths):
    Classical std = 1.3767
    Optimized std = 1.3230  (-3.9% improvement)

  On independent test (10,000 paths):
    Classical std = 1.3411
    Optimized std = 1.3667  (+1.9% WORSE!)

The "improvement" was just noise fitting!

3. SAMPLE VARIANCE EFFECT
--------------------------

Standard error of std estimate from MC:
  SE(std) ≈ std / √(2N)

For N=2,000, std≈1.3:
  SE ≈ 1.3 / √4000 ≈ 0.021

This means measured std can fluctuate ±0.04 (2σ confidence)

When we test 11 different A values, we WILL find one that happens
to be lower by ~0.04 just due to random chance.

This is exactly what happened - we selected A based on noise!

4. REAL DATA VALIDATION
------------------------

ABM on real TSLA/AAPL data provides ground truth:
  - Uses actual historical prices (not simulated GBM)
  - No Monte Carlo randomness
  - Direct comparison of strategies

Result: Classical consistently better than Optimized

This confirms that optimization improvements were spurious.

5. GENERALIZATION FAILURE
--------------------------

Pattern across all tests:
  - Optimization works on calibration sample (by design)
  - Fails to generalize to independent test data
  - Fails on real market data

Classic ML problem: overfitting to training set

But here it's worse - we're not even using ML!
Simple grid search on noisy objective function.

================================================================================
KEY INSIGHTS
================================================================================

1. Don't try to "improve" mathematically optimal formulas
   - Leland's derivation is rigorous and exact
   - Empirical "improvements" are likely noise fitting

2. Finite sample optimization is dangerous
   - 2,000-10,000 MC paths seems large but isn't
   - Sampling variance creates spurious optima

3. Real data validation is critical
   - ABM on real data revealed the truth
   - Simulated data can hide overfitting

4. Sometimes simpler is better
   - Classical formula: instant computation, no calibration
   - Optimized: requires expensive MC, doesn't generalize

5. Classical financial theory is powerful
   - 40-year-old formula (1985) still optimal
   - Modern optimization/ML doesn't always beat theory
